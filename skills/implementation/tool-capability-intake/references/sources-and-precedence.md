# Sources And Precedence

For tool capability intake in `dotfile-vnext`, prefer:

1. `AGENTS.md`
2. `.codex/config.toml`
3. `docs/codex_framework/*`
4. Active `.cursor/rules/framework-*.mdc` guidance already loaded for the task
5. Existing repo roles, playbooks, inventory, and validation entrypoints
6. Official upstream docs for the tool and installer path
7. Live preview/apply evidence

Do not choose installer or lifecycle strategy from memory when current upstream
docs can answer it.
