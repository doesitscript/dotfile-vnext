# Sources And Precedence

For project capability-surface audits in `dotfile-vnext`, prefer:

1. `AGENTS.md`
2. project `skills/catalog.yaml` and `skills/README.md`
3. active framework rules
4. runtime `.cursor/skills/catalog.yml`
5. legacy `.cursor/skills/*` bodies

Runtime mirrors and legacy `.cursor` skills can inform the audit, but they do
not outrank the repo's current project-skill source of truth.
