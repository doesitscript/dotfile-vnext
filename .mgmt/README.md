# .mgmt — controller-side management files (Mac as source of truth)

This directory holds files used when the **Mac is the Ansible control node** and source of truth for SSH and OpenSSH.

- **`ansible_ssh.pub`** — Public key for the shared Ansible SSH key pair. Deployed to Windows `%USERPROFILE%\.ssh\authorized_keys` and to WSL `~/.ssh/authorized_keys` by bootstrap playbooks. The private key lives in `~/.ssh/id_ed25519_ansible` on the Mac (and in `vault/ansible_ssh.vault.yml`). Do not commit the private key; `ansible_ssh.pub` is safe to commit.

Other files here (e.g. `requirements.sha256`, `ansible.log`) are generated by the tooling and used for dependency and run state.

See `bootstrap/openssh_host_keys/README.md` for host key generation and vault; see `docs/setup_openssh_via_winrm_summary.md` for OpenSSH-on-Windows setup.
