# server_225/wsl2

Legacy/reference role from the older Server-225 WSL2 setup.

This role should not be treated as the preferred long-term model for Linux companion setup on Server-225.

Current interpretation:
- keep as reference material
- mine useful steps from it later
- translate those steps into a future Hyper-V Ubuntu VM path instead of extending the WSL2 approach directly

This makes it a legacy source of ideas, not an active direction of travel.
