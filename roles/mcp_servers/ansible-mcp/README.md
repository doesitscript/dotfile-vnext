# ansible-mcp (frozen)

Frozen snapshot of the standalone Ansible MCP server role.

This role is kept for reference/rollback only. It is no longer included in
`playbooks/mac/mcp_servers.yaml` and should not be version-bumped for normal
workspace maintenance.

## Documentation

For information on configuring the VS Code Ansible extension, including settings for the MCP server path, please see the official documentation:

[Ansible VS Code Extension Configuration](https://docs.ansible.com/projects/vscode-ansible/configuration/)

The documentation covers all `ansible.*` path properties for the MCP server.
