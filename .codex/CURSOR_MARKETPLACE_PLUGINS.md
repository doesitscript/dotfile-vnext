# Cursor Marketplace Plugins

Managed by `roles/cursor`.

These entries are **Cursor marketplace plugins**, not normal VS Code/Cursor
extension IDs. Do not try to manage them with `cursor --install-extension`.

## Required On `mac-dev`

- `superpowers` — install in Cursor with `/add-plugin superpowers`; macOS manifest probe:
  `/Users/joshc/.cursor/plugins/cache/cursor-public/superpowers/*/.cursor-plugin/plugin.json`
