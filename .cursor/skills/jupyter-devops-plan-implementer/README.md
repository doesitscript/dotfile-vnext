# Jupyter DevOps Plan Implementer Capability

This skill wraps the repo-local execution policy for the staged Jupyter DevOps
implementation plan set under `docs/intake/jupyter-devops-implementation-plans/`.

It exists to replace long repeated launch prompts with one explicit skill
invocation while preserving the real stop conditions and plan order.

launcher and the preserved long-form execution contract do not drift apart.
