# Ansible Knowledge Gate Capability

This skill keeps Ansible work grounded in repo truth and current Ansible
authority before design or implementation.

It is intentionally separate from the NetBox gate. Ansible owns automation
shape: roles, playbooks, modules, variables, lifecycle state, idempotence, and
validation. NetBox owns infrastructure modeling and source-of-truth shape.

## Owned Files

- `.cursor/skills/ansible-knowledge-gate/SKILL.md`
- `.cursor/skills/ansible-knowledge-gate/README.md`
- `.cursor/skills/ansible-knowledge-gate/capability.yml`
- `.cursor/skills/ansible-knowledge-gate/references/knowledge-receipt.md`
- `.cursor/rules/ansible-knowledge-gate.mdc`

## Update Rule

Update the skill, manifest, reference, and companion rule together. The
`owned_files` list in `capability.yml` is the update/remove source of truth.
