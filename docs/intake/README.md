# Intake Notes

This folder is for shaped ideas that are more than raw research but not yet adopted plans.

This README is a mental model for the human side of the project. It is not an active rule file for Codex to follow.

## Mental Model

- `research`
  Facts, references, options, and evidence gathering.
- `intake`
  Promising candidate approaches that have been massaged enough to discuss seriously, but are not yet chosen.
- `plan`
  A chosen path with clearer implementation intent.
- active framework/process docs
  Current operating truth for how the repo and Codex workflow should behave.

## What Belongs In `docs/intake/`

- candidate approaches worth revisiting
- massaged research that is close to plan-level usefulness
- documents that may become plans later
- promising implementation directions that still need a decision

## What Does Not Belong Here

- active rules for Codex behavior
- final implementation runbooks
- random loose notes with no clear decision value

## Why This Folder Exists

Some docs are too developed to feel like raw research, but too provisional to pretend they are approved plans.

`docs/intake/` gives those documents a home without overstating their status.
