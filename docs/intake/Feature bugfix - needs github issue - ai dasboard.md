- expected vs actual path

  - state-tracking failure

  - planning failure
  - validation failure
  - recovery failure

- confidence / uncertainty markers

  - core model
  - orchestration layer
  - tool router
  - artifact generator
  - output validator

  - regenerate

  - downgrade to text-only answer

- failure summary

  Which components need work.

- detection opportunity  
  The earliest point where the failure could have been caught.

- prevention strategy  
  What permanent guard would stop recurrence.

- swimlane diagram
