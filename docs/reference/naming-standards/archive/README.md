# Naming Research Archive

This folder contains older prose-heavy naming research. Files here are no
longer active schema authority. Use the compact YAML files one directory up for
current naming decisions.

Status suffixes:

- `-integrated`: useful decisions were captured in active schema files.
- `-not-yet-integrated`: source material remains under review or contains stale
  choices that must be reconciled before use.
- `-tbd`: retained for later review, not implemented.

When pulling anything out of this archive, add or update an entry in
`../source-reconciliation.yml`.
