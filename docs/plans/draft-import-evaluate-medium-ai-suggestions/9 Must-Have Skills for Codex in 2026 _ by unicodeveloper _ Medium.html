9 Must-Have Skills for Codex in 2026

unicodeveloper
10 min read
·
Apr 28, 2026

The guide to agent skills that change how you use OpenAI Codex in production.

I have been at the receiving end of Claude rate limit issues recently. I sat there looking at the error for a minute. Then I opened Reddit to see if it was just me. It wasn’t. The r/ClaudeCode thread from that week had hundreds of replies. Max plan subscribers everywhere, $100/month, $200/month, all hitting zero in under 90 minutes. I am/was on the £90 per month plan.

One user documented a session where their usage jumped from 21% to 100% on a single prompt. Not a large one. A normal one. GitHub issue #38335 was already live: “Claude Max plan session limits exhausted abnormally fast since March 23, 2026.” The same regression was documented across #38029, #38239, #38335, #38345, #38350, #38357, #39649, #41084, and #41930, counter-desync bugs, session-resume bugs, and the end of the 2x off-peak promo all converged at once, with Anthropic engineer Thariq Shihipar confirming on X (March 26) that peak-hours session limits had been intentionally tightened for ~7% of users.

The cause, eventually: two cache bugs silently inflating token consumption by 10–20x. Every turn treated as the first. No caching. Costs compounding. The full session budget gone in the time it takes to have a morning standup.

This wasn’t new. It was the latest chapter in a pattern that started when Anthropic announced rate limits to “curb Claude Code power users”.

I opened a new terminal tab and installed OpenAI’s Codex! That was three weeks ago. I haven’t abandoned Claude, but now I use both!

This guide covers the Codex skills I use and the difference in my experience of using Codex and Claude Code and also how to migrate your Claude setup in under an hour.

What Is OpenAI Codex CLI in 2026? (Not the 2021 API)

If you tuned out “OpenAI Codex” because you remember the code-completion API that got shut down, you missed a completely different product.

The Codex CLI launched on April 16, 2025 and now have ~4 million weekly active users. This was confirmed by Sam Altman on April 8, 2026.

It runs in your terminal, reads your repo, edits files, runs tests, and commits. Same category as Claude Code. Different execution model, different strengths.

Install OpenAI Codex CLI:

npm i -g @openai/codex
codex

The Codex Skills to have in 2026

Skills support launched for Codex in December 2025. A skill is a “SKILL.md” file in “~/.agents/skills/”.

Codex loads it automatically when the task matches. You write the instructions once, every future session inherits the behavior. Here are the ten skills you can also install to have a great experience using Codex.

1. WarpGrep. AI Code Search Subagent

The problem: Ask Codex to find where a function is used across a large codebase and it will grep, read adjacent files, load unnecessary context, and spend 75 seconds on something that should take 5. The main model context fills with search noise before reasoning even starts.

What it does: WarpGrep is a reinforcement-learning-trained search subagent that runs in an isolated context window. It fires 8 parallel tool calls per turn: grep, read, list and returns only the file:line-range spans the main model needs. Up to 36 tool calls complete in under 5 seconds. Median codebase search: 5 seconds. Claude Code Explore subagent on the same task: 75 seconds.

Paired with WarpGrep, Codex hits 59.1% on SWE-bench Pro, 3.1 points higher, with 17% fewer input tokens and 15.6% lower cost per task.

How to install:

# Add to ~/.codex/config.toml
[mcp_servers.morph-mcp]
command = "npx"
args = ["-y", "@morphllm/morphmcp"]

[mcp_servers.morph-mcp.env]
MORPH_API_KEY = "your-api-key"

Get your API key at morphllm.com

Documentation: docs.morphllm.com/sdk/components/warp-grep

The real value: This is the only skill on this list that directly improves benchmark scores. It’s not a workflow enhancement. It’s a performance upgrade. Install it first.

2. create-plan. Force a Plan Before Execution

The problem: You describe a feature. Codex starts writing files. Twenty minutes later you realize it went in a direction you didn’t want, built abstractions you didn’t need, and touched files that didn’t need touching. The prompt was fine. Execution started before the approach was clear.

What it does: Forces Codex to produce a written implementation plan before it opens a single file, which files change, what approach, what edge cases, what tests need to pass. You review and approve. Codex executes against a target you’ve signed off on.

How to install:

$skill-installer create-plan

The real value: The wrong-direction session is the most expensive thing in agentic coding. It burns rate limits, takes time to unwind, and erodes trust in the tool. “create-plan” makes the plan visible before execution starts.

3. gh-fix-ci. Automatically Fix Failing CI

The problem: CI fails. You open the logs, copy the error, paste it into a new Codex session, explain the test suite, wait for a fix, apply it, push again. Repeat. 45 minutes on something that should take 5.

What it does: Reads the failing GitHub Actions output directly, identifies the root cause, commits the fix. Handles flaky imports, missing mocks, test ordering issues, lint rules, and environment variable mismatches.

How to install:

$skill-installer gh-fix-ci

The real value: Most CI failures are the same five categories in different clothing. “gh-fix-ci” turns them into a background task.

4. Valyu. Web Search + Deep Research + Access to Specialised Sources

The problem: Agents like OpenAI Codex struggle when tasks require real-world data. Paper search, academic research, GitHub search, economic indicators, or academic papers. Without integrations, they either hallucinate or defer.

What it does: Valyu’s MCP server connects Codex to dozens of structured and specialized data sources through a single integration, including:

  • Paper search (ArXiv)
  • GitHub search
  • Search over docs of any kind
  • coverage across major academic and scientific sources

Valyu is optimized for fresh, real-time queries, and has shown strong performance on time-sensitive question answering.

How to install:

# Add to ~/.codex/config.toml
[mcp_servers.valyu]
command = "npx"
args = ["-y", "@valyu/mcp-server"]
[mcp_servers.valyu.env]
VALYU_API_KEY = "your-api-key"

Get your API key at platform.valyu.ai

Example queries now possible:

  • “Find merged pull requests across major JS projects that bumped React to a new major version, and summarize the migration steps they took”
  • “I want to implement FlashAttention from scratch. Point me to the original paper, follow-up papers (FA2, FA3), and the cleanest reference implementations.”
  • “Show me ArXiv papers and blog posts that explain how to train a small LLM (~1B params) end-to-end on a single 8xH100 node.”
  • “What are the published recipes for fine-tuning a 7B model with LoRA on a single 24GB GPU? Include hyperparameters.”
  • “Find papers and official documentation describing how DeepSpeed ZeRO-3 partitions optimizer states, gradients, and parameters.”
  • “Compare the official implementations of vLLM, SGLang, and TensorRT-LLM for batched LLM inference.”
  • “Show me how popular open-source projects structure their retry logic for HTTP requests in Go”

The real value: This turns Codex from a closed system into one that can reason over live, structured, real-world data, not just what’s in the repo.

5. gh-address-comments. Handle PR Review Comments Automatically

The problem: A reviewer leaves 14 comments on a pull request. You come back Monday with cold context, spend 20 minutes re-reading the scope, work through comments one by one, switching files, tracking what’s been addressed.

What it does: Reads every review comment, groups by type, addresses each in a single session. Commits changes and responds inline. Reads surrounding code context per comment, not just mechanical style fixes.

How to install:

$skill-installer gh-address-comments

The real value: The review-response cycle is where most development velocity goes. “gh-address-comments” runs in the time it takes to get a coffee.

6. frontend-skill. Stop Generic AI UI Output

The problem: Ask any coding agent to build a UI and you get Inter, neutral grays, 8px border-radius on everything, and a layout that looks generated because it was.

What it does: Overrides default aesthetic decisions before any code gets written. Bans overused system fonts, requires a typography rationale, forces a color palette before the first CSS line.

How to install:

mkdir -p ~/.agents/skills

git clone https://github.com/vipulgupta2048/codex-skills.git

cp -r codex-skills/frontend-design ~/.agents/skills/

The real value: Without this skill, Codex builds UIs that work. With it, Codex builds UIs that look like someone made a decision.

7. stop-slop. Remove AI Writing Patterns from Prose

The problem: Codex writes clean code and mediocre prose. Every README has em-dashes, “it’s worth noting that”, and the rhythm of something generated rather than written.

What it does: Strips AI writing tells from documentation, READMEs, commit messages, and comments. Rules out em-dashes, throat-clearing openers, binary contrast structures, passive voice stacking.

How to install:

mkdir -p ~/.codex/skills
git clone https://github.com/hardikpandya/stop-slop.git ~/.codex/skills/stop-slop

The real value: The code can be excellent and still lose a star because the docs feel hollow.

8. Superpowers

What it does: It launches a subagent-driven-development process, having agents work through each engineering task, inspecting and reviewing their work, and continuing forward. Built on top of a set of composable skills and some initial instructions that make sure your agent uses them.

How to install:

  • Open the plugin search interface
/plugins
  • Search for Superpowers
superpowers

Select Install Plugin and then it installs.

9. Codex Security. AI Threat Modeling and Vulnerability Detection

The problem: Most teams don’t do threat modeling. It’s slow, requires security expertise they don’t have in-house, and produces documents out of date the week they’re written.

Note: This is not a skill. This is feature baked into Codex Cloud!

What it does: OpenAI’s official application-security agent, launched March 6, 2026 as a research preview. Analyzes repository structure, maps trust boundaries, generates an editable threat model, then searches for vulnerabilities, pressure-testing findings in sandboxed environments.

Beta results: 1.2 million commits scanned, 792 critical findings and 10,561 high-severity issues identified. Critical issues appeared in under 0.1% of commits. Available on Pro, Enterprise, Business, and Edu plans.

How to activate:

You have to signup for Codex Cloud first.

Then follow the instructions to connect your repo, start a security scan and build a threat model.

The real value: Once the threat model exists, every subsequent Codex session has security context. It’s not a one-time scan. it’s infrastructure.

The Best Claude Code + Codex Workflow for 2026

After three weeks, I haven’t fully switched. The split makes sense.

Use Claude Code for:

  • Complex reasoning over large codebases (1M context on Sonnet 4.6/Opus 4.7 holds up well. Opus 4.6 scored 78.3% on MRCR v2, the highest among frontier models at that length)
  • Tasks where thoroughness matters more than token efficiency (Claude uses ~3-4x more tokens but wins blind code-quality reviews ~67% of the time)
  • Interactive debugging where you want to stay in the loop
  • Architecture planning and multi-file refactors where coherence across a long task chain matters

Use Codex for:

  • Terminal-heavy work (GPT-5.3-Codex leads Terminal-Bench 2.0 at 77.3% and GPT-5.4 at 75.1%, vs Opus 4.7 at 69.4% — Opus 4.7 narrowed the gap but Codex still leads)
  • Background tasks. Fire a cloud task via Codex Cloud, review the PR an hour later
  • Very very complex features. I haven’t tried this personally but I have seen Redis author mention this publicly.
  • High-volume sessions where Claude’s rate limits would block you (ChatGPT Plus at $20 generally allows more sessions than Claude Pro at $20 on equivalent workloads)
  • Parallel work across multiple codebase areas, where the async cloud-sandbox model shines
  • Any workflow where the 10 skills above are running automatically

The two-agent review loop some developers use:

Claude Code generates the implementation plan → Codex reviews for edge cases → Claude executes → Codex does final review.

Both CLIs support non-interactive mode (`claude -p` for Claude Code), so you can script the handoff.

FAQ: OpenAI Codex in 2026

What is OpenAI Codex CLI?

OpenAI Codex CLI is an agentic coding assistant that runs in the terminal, launched April 16, 2025. It reads your repository, edits files, runs tests, and commits code. It is not related to the original Codex API (2021–2023). It is Apache-2.0 licensed and has 3 million weekly active users as of April 2026.

How is Codex different from Claude Code?

Both are terminal-based agentic coding tools. Codex uses 3–4x fewer tokens per task, scores higher on terminal benchmarks (77.3% vs 65.4% on Terminal-Bench 2.0), has a 200K context window, and uses TOML for MCP configuration. Claude Code scores higher on SWE-bench Verified (80.8%) and offers a 1M context window on newer models.

How do Codex rate limits work?

Codex uses a dual-window system: a 5-hour window and a weekly window, both running simultaneously. Every request reduces both. When either hits zero, you are blocked. Check usage at `chatgpt.com/codex/settings/usage` or type `/status` in the CLI.

How do I migrate from Claude Code to Codex?

Run `cp CLAUDE.md AGENTS.md` to migrate your project instructions. Rebuild your MCP server configs in `~/.codex/config.toml` (TOML format). Reinstall your skills in `~/.agents/skills/`. For complex setups, use the `cc2codex` open-source migration tool.

What are Codex skills?

Codex skills are SKILL.md files stored in ~/.agents/skills/ that give Codex reusable, persistent behaviors. They are part of the Agent Skills open standard cross-platform across Codex, Claude Code, Gemini CLI, and Cursor. Skills launched for Codex in December 2025.

What is WarpGrep?

WarpGrep is a reinforcement-learning-trained code search subagent by Morph that ships as an MCP server (`@morphllm/morphmcp`). It runs 8 parallel tool calls per turn and completes codebase searches in ~5 seconds vs ~75 seconds for Claude Code Explore. Paired with Codex, it raises SWE-bench Pro scores to 59.1% (+3.1 points).

Is Codex free?

Codex is included with ChatGPT Plus ($20/mo), Pro ($100/mo), and Pro ($200/mo) plans. Higher tiers get proportionally higher rate limits. Additional credits can be purchased when limits are reached.

What is AGENTS.md?

“AGENTS.md” is Codex’s equivalent of Claude Code’s “CLAUDE.md”, a markdown file at the repository root that gives the agent persistent project-level instructions. The formats are identical, making migration a direct copy.

How do I add an MCP server to Codex?

Use `codex mcp add server-name — npx -y @package/name`, or edit `~/.codex/config.toml` directly with a `[mcp_servers.name]` block.

Note: Codex uses TOML format, not JSON, a “config.json” file will be ignored.

What is Codex Security?

Codex Security is OpenAI’s application-security agent, launched March 6, 2026 as a research preview. It generates threat models, scans for vulnerabilities, and validates findings in sandboxed environments. In beta it scanned 1.2 million commits and found 10,561 high-severity issues. Available on Pro, Enterprise, Business, and Edu plans.
