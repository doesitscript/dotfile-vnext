# Implementer note — before activation

Do not begin the storage implementation merely because broad research exists.
Before the first Implementer pass, require the plan's implementation-readiness
brief and its target preflight. The brief is a contract input, not a sign-off.

At implementation time, preserve the mature Implementer boundaries: own source
changes, live apply, receipt evidence, and `review_ready_for_evaluator_*`; do
not create evaluator feedback, waiting, or approval artifacts.

If the brief has a blocking gap, return it to the Researcher/Coordinator with a
specific question. If implementation evidence changes a decision, record the
deviation and why in the receipt before requesting evaluator review.
