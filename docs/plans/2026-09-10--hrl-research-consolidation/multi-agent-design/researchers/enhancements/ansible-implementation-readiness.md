# Enhancement — Ansible implementation-readiness research

Use the existing `ansible-knowledge-gate` as a specialized researcher path when
domain research reaches an Ansible implementation decision.

The Researcher should produce a readiness brief, not an unbounded Ansible
survey. It must answer the exact implementation questions: owner surfaces,
module/pattern fit, lifecycle, target scope, preflight, verification, undo, and
open gaps. Consult the Ansible MCP's Zen, content-best-practice guidance, and
resources when callable, then corroborate implementation specifics using repo
evidence and authoritative documentation.

See [`../../knowledge-capabilities/ansible-implementation-knowledge.md`](../../knowledge-capabilities/ansible-implementation-knowledge.md).
