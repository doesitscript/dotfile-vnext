# Researcher note — before activation

Separate domain research from implementation research. For the storage plan,
the first explains the right storage outcome; the Ansible capability explains
how the repo can safely own it.

Before handing work to an Implementer, produce the implementation-readiness
brief and classify each unanswered question as resolved, non-blocking, or
blocking. List source availability separately from source content: an MCP being
configured is not evidence that it was callable in the relevant runtime.

Do not apply the solution or issue evaluator approval. Your handoff makes the
next role smarter and auditable.
