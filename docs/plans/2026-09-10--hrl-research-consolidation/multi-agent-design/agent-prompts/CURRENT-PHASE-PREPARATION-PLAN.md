# Current-phase preparation plan (thin)

Preparation stage only: Coordinator + Researcher produce a bounded
implementation-ready packet for the established Implementer/Evaluator loop.

**Contract:** [execution-contract.md](execution-contract.md)  
**Orchestration map:** [../orchestration/01-critical-path--expert-to-evaluator.md](../orchestration/01-critical-path--expert-to-evaluator.md)

## Passes

1. Coordinator frames scope / decision questions (`compose`).
2. Researcher reviews evidence and returns readiness / gaps (`review-plan`).
3. Coordinator releases or revises (`release` / re-review).

Outputs land in the preparation run directory (handoff / research / release),
not as host Apply. Downstream implementation consumes the campaign **refined
technical handoff**, not this preparation chat.
