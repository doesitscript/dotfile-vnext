# Enhancement — route knowledge capabilities from problem intake

The Onsite Expert does not need to know every implementation detail. Its
responsibility is to identify the kind of uncertainty and assign the smallest
knowledge capability that can resolve it.

For an infrastructure problem, separate:

- domain questions: what is happening and which outcome is appropriate;
- implementation questions: how repository automation should make that outcome
  safe, idempotent, verifiable, and reversible.

Record the capability trigger, desired research output, priority, and blocking
questions in the researcher handoff. Keep a capability's sources advisory until
their actual availability is proven in that task.
