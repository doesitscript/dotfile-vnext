# Onsite Expert / Coordinator note — before activation

Before activating implementation roles, turn the problem into named decision
questions and select only the knowledge capabilities that answer those
questions. For storage, route domain uncertainty and Ansible implementation
uncertainty separately.

Record the intended handoff path, owner for each brief, activation condition,
and the external wakeup/operator path. The Onsite Expert remains the guardian
of problem fit: it rejects a technically plausible implementation if it does
not solve the original storage problem safely.
