# Expert consultation requests

When Implementer (or Evaluator) hits a **named technical choice** that is not
already settled as Best/Preference in the packet, do **not** ask the human.

1. Copy `_TEMPLATE.md` to a new file in this folder.
2. Fill the exact fork, cited research, affected owners, acceptance test,
   `return_to`.
3. Parent Light run: set `consultation_request_path` to that absolute path.
4. Runner deploys On-site Expert → Researcher sidecar; pair continues on the
   returned Best recommendation under `lab_recreatable_autonomy`.
