# On-site Expert response instructions

Review both question sets in this folder and the cited campaign evidence. Write
one timestamped Markdown recommendation in `response_on-site_expert/`.

For every recommendation:

- label it **Best recommendation**, **Preference**, or **No recommendation yet**;
- state the motivation and expected operational benefit;
- identify the supporting findings and exact artifact paths;
- state assumptions, risk, validation, rollback/wait condition, and any
  remaining read-only evidence needed;
- distinguish verified facts from inference and preferences.

Prioritize a concrete default path when evidence supports one. If it does not,
say why a recommendation cannot responsibly be made and give the narrowest
next read-only check. Do not grant Apply authority, select destructive targets
without evidence, or repeat discovery that the campaign already captured.
