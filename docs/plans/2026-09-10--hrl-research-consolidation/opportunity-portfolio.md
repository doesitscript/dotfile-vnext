# Opportunity portfolio

This is an opportunity inventory from the storage campaign and governed
multi-agent loop. It is not a product decision or market study.

| Opportunity | Form | Evidence in this work | First bounded slice |
| --- | --- | --- | --- |
| Governed agent change-control plane | Product or internal platform | Causal role artifacts, authority gates, evaluator separation, owned cleanup | One infrastructure change with audit export and approval gates |
| Evidence-first infrastructure readiness | Feature or consulting offer | Read-only discovery maps hosts, disks, K3s/PVC, and workloads into decision gaps | Inventory-to-decision report for storage/Kubernetes/virtualization |
| Agent-run audit ledger | Open-source core plus commercial layer | Hashes, receipts, run manifests, failed-attempt preservation | Artifact schema, causal-chain validator, campaign export |
| Safe Ansible change workbench | Developer/operations tool | `--limit` safeguards, required probes, fail-closed gates, Apply/Verify/Undo | Discovery receipt to gated Ansible execution packet |
| Operator observability console | Product feature or reusable tool | Dashboard exists; safe summaries and token-free console monitoring are defined gaps | Named-session console for slots, gate, process state, and latest event |
| AI infrastructure-storage service | Consulting/implementation offer | Storage, cache/PVC, virtual-disk, rollback, and decision workflows connect | Fixed-scope readiness assessment plus implementation packet |
| Causal agent handoff protocol | IP, schema, or standard | Campaign/run/role/hash/responds-to/acceptance fields are reusable | JSON/YAML schema with conformance fixture |

## Promising but unproven

- Portable multi-agent capability library: needs validation on an unrelated
  change class.
- Autonomous remediation: intentionally not proven; authority, target,
  rollback, and evaluator evidence must precede it.
- Campaign analytics: needs a privacy model and normalized trace export.

## Assets worth preserving

- Separation of runtime visibility, implementation evidence, evaluator
  judgment, and live-Apply authority.
- Exact owned-process lifecycle rather than broad process killing.
- Causal artifacts that reject stale or cross-run approval evidence.
- Discovery that turns unknowns into explicit decisions instead of invented
  infrastructure defaults.

## Direction

Do not build a product now. Preserve the evidence contract, add a normalized
campaign trace export, then validate the model on one unrelated change class.
