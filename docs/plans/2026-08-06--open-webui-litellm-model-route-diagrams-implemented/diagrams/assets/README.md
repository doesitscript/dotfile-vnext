# Diagram assets

Icons used by rendered diagrams in this directory. Paths are relative
to the diagram output directory (any Mingrammer provider under
`resources/` → `assets/`).

```text
  assets/aws/general/user.png
  assets/onprem/client/client.png
  assets/onprem/compute/server.png
  assets/onprem/container/docker.png
```

Do not point at Docker absolute paths under `/usr/local/...`.
