## What to check on ASUS ROG GT6

Admin: GT6 LAN IP **`http://192.168.50.1/`** (Network Map). Confirm you are on the **primary** mesh node, not a satellite.

### 1. Prove whether UPnP can even work (do this first)

Network Map / **WAN IP**:

- If WAN IP is **`192.168.0.x`** (typical `.254` upstream) → GT6 is **LAN client of AT&T**. UPnP maps on GT6 only open ports on **`192.168.0.x`**, not on **`99.63.7.93`**. Off-LAN Steam/DBD joins fail even if GT6 UPnP is On.
- Wanted: GT6 WAN IP **= public** (`99.63.7.93` or similar), AT&T in **IP passthrough / DHCPoE** to the GT6 WAN MAC.

AT&T box (`http://192.168.0.254/`): **IP Passthrough** / DHCPoE to GT6. Same lesson as 2026-07-24 on this PC.

### 2. GT6 UPnP toggle (AsusWRT-style; stock GT6)

**Advanced Settings → WAN → NAT Passthrough** (sometimes WAN → Internet Connection):

- **Enable UPnP** = On  
- Leave PPTP/L2TP/IPSec/RTSP passthrough On unless you have a reason  

Then **Advanced Settings → WAN → NAT Passthrough / UPnP** or System Log → **Port Forwarding / UPnP**:

- After launching the game, look for rows to **`192.168.50.133`** (Steam **27036**, plus ephemeral UDP).  
- **Empty list while a game is hosting** = GT6 is not taking IGD requests (UPnP off, AiProtection, or double NAT).

### 3. Do not fight UPnP with the other NAT toys

Same WAN page / **Firewall** / **AiProtection**:

- **Virtual Server / Port Forwarding** overlapping the same ports as UPnP  
- **Port Trigger**  
- **Game Boost / Adaptive QoS / Gear Accelerator** (can rewrite/drop UDP)  
- **AiProtection / Trend Micro** IPS or “two-way IPS”  
- **IPv6** firewall if friends are IPv6 (PC has AT&T IPv6 DNS `2600:1700:48fd:800f::1`)

### 4. DHCP identity for this PC

| Row | Action |

Ethernet on the PC is still **disconnected**. Wired LAN is the better first hop if Wi-Fi loss is in play (11–14% to `50.1` on 2026-07-24).
